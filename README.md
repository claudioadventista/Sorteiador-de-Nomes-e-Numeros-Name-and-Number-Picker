Sorteador de nomes e números, muito completo.
Com senha para proteger o andamento do sorteio.
Em HTML, CSS e JAVASCRIPT.
Para usar em PC ou notebook.
Funções especiais como Sortear Manualmente, e Retornar Sorteado.
Na imagem do cadeado do Formulário Trocar Título, cria a senha.
Na imagem do cadeado do Modal Áudio, apaga a senha.
